# Governance

nv-rs is a personal project maintained by slaterain. Contributions and discussion are welcome, but this is not a community-vote project. The maintainer makes final decisions about priorities, design, accepted changes and releases.

Work is organized around the active milestone in [MILESTONES.md](MILESTONES.md). Proposals outside that scope may be deferred. Issues and pull requests help make work visible and reviewable; opening one does not commit the maintainer to accept it or to a delivery date.

The project does not redistribute Fallout: New Vegas data. Contributors and testers use their own lawful installation, and must not submit game assets, recordings, raw decompiler exports or databases to the repository. Translated decompiled logic and prototype-symbol names follow [ADR-0003](adr/0003-decompiled-code-in-the-project.md) and [ADR-0002](adr/0002-xbox-prototype-symbols.md); [LEGAL.md](../LEGAL.md) summarises the project's position.
