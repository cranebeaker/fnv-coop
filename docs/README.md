# Documents

nv-rs runs Fallout: New Vegas through the engine port: FalloutNV.exe 1.4.0.525 translated
function by function into Rust (`crates/engine*`), started on the player's own exe by
`crates/host` and run by `nv-viewer` (`viewer/`).
