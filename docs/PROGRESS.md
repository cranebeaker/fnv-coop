# Co-op progress checklist

Story co-op for Fallout: New Vegas, built on [nv-rs](https://github.com/slaterain/nv-rs) by slaterain.
This page is the plain-language version of the full test checklist ([COOP-CHECKLIST.md](COOP-CHECKLIST.md),
709 items, regenerated by `coop-sim checklist`). Last updated 2026-11-02.

How to read the boxes:

- `[x]` real game: a host and a guest run on real game data and a script checks the result
- `[x]` headless: passes the fast in-process tests, and the in-game check is next
- `[ ]` building: being written now, or waiting on something outside this project

## Joining and staying in sync

- [x] real game: host and guest connect over UDP and share one world
- [x] real game: the guest gets a full snapshot of the host's world when it joins
- [x] real game: rejoin after a lost connection, including a blackout
- [x] real game: out-of-sync detection and repair under bad Wi-Fi
- [x] headless: join codes (`NVRS-...`) for sharing a session
- [x] headless: version and mod-list mismatch refused at join with a clear message
- [ ] building: Steam (Spacewar) invites. The code is written and tested with a mock; it needs a test with two real Steam accounts

## Story

- [x] real game: quest stages, objectives, globals and topics shared
- [x] real game: per-player quests, inventories and skills where the campaign rules say so
- [x] headless: rewards given once, to the right players
- [x] headless: all 487 quest rules (base game, Dead Money, Honest Hearts, Old World Blues, Lonesome Road) walked quest by quest. 480 pass; two DLC quests fail on per-player quest variables and are being fixed
- [ ] building: the DLC quest rules matched to the runtime quest ids for any load order

- [x] real game: the other player appears and moves, with a name tag

## How it is tested

- [x] 709-item checklist that runs in about 10 seconds with no game window
- [x] 10 scripted two-player runs in the real game, each with a "twin" that must fail, so a check cannot pass by doing nothing
- [x] a headless simulator that replays the same scenarios on the real game data across seven network conditions and many random seeds
- [x] a live control port to inspect running game windows, take screenshots and replay a scenario after each file save

## The engine underneath

Co-op can only go as far as the engine does. nv-rs currently plays Doc Mitchell's house, the opening
and Goodsprings. Upstream is switching on the rest of the game, system by system. A measured sweep of
the base game and all four DLCs shows 99.8 percent of the script calls in the game data are handled,
and 97 percent of main-quest stages run. The rest of the gap is AI, presentation and assets, and it is
upstream's to schedule. We contribute fixes there where we can.

## Not planned
