# Milestone 3: the Direct3D 9 calls in the race menu, for `nv-trace d3d` (draw-by-draw state).
# Device methods are named by the port's addresses for them: 7e020200 + 4 * vtable slot
# (crates/engine-core/src/units/platform/d3d9device.rs); the real recorder hooks the same slots
# of the game's device. Calls are stdcall with `this` (the device) as w0 on both sides.
# D3DX imports are named by the exe's import slots (00fdf3fc ...), as the port registers them.
#
# Objects are named by their creation, recorded from the start: textures from files by the hash
# of the file bytes (hash=w1:w2), shaders by their bytecode (shader=w1), declarations by their
# elements, the rest by their creation parameters; the out pointer at return (rdump) ties the
# object's address in each run to its name.
# The state calls are recorded from RaceSexMenu::Create to the end of the window (state set
# earlier and never again shows as unknown on both sides); the draws and Present only in the
# window (frames=S..E: frames S to E-1 counted from the first call let through).
