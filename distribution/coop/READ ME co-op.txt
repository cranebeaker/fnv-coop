FNV Co-Op on nv-rs
==================

Play the story of Fallout: New Vegas together. One player hosts the story, the others join it.
This package is nv-rs (see READ ME.txt) with the co-op layer in it. It has no game files: each
player needs their own installed Fallout: New Vegas, version 1.4.0.525, with the same add-ons.

This is an early alpha. Tell us what happens: https://github.com/cranebeaker/fnv-coop/issues


Start
-----
1. Each player extracts the whole ZIP as READ ME.txt says, and runs Play.exe once alone. That
   first start finds the game and reads the graphics card and the sound device. Close the game.
2. Each player double-clicks "Play Co-op.exe". A window asks for your name, and has the buttons
   below. It keeps your choices for the next time (userdata\coop.ini).
3. The host presses Host.
   - Friends in the same home network: leave the address box empty.
   - Friends over the internet: type your public address, and forward UDP port 27961 to your PC
     in your router. Or all players use a private network app (Tailscale, ZeroTier, Radmin VPN),
     and the host types its address in that app.
   - With Steam (see below), tick "Host on Steam too": Steam friends join with no port forwarded.
   When the game has started, a window shows the join code (NVRS-...) and copies it. Send it to
   your friends.
4. Each friend pastes the join code in the Join code box and presses Join.
5. Everybody presses New Game (or loads the same save). Each player makes their own character at
   Doc Mitchell's. When a guest is in the world, the game moves it to the host.

"Play Co-op.cmd" still works: it asks the same in a console (host or join, name, address).


Steam invites
-------------
Steam invites need Steam running and signed in on each PC, and Valve's steam_api64.dll next to
Play.exe (STEAM.txt says whether this package has it). Then:
- The host presses "Invite a Steam friend". In the game, the Steam overlay's invite dialog opens
  once you are in the world; F6 opens it again. If the overlay does not show in the game, invite
  from the Steam friends list instead (right-click the friend, Invite to game).
- The friend presses "Join a Steam friend" before or after the invite. Their game waits up to two
  minutes for a friend who hosts or an invite, then joins through Steam.
Accepting an invite in the Steam client while the game is not running starts Spacewar, not this
game: start "Join a Steam friend" first.


Voice chat
----------
On unless you choose Off. Push to talk: hold the key you chose (Backslash unless you changed it).
Open microphone: the game sends when you speak. In the game, F8 turns your microphone off and on,
F7 the other players' voices. You hear each player from where they stand, quieter far away.
The game uses Windows' default microphone and speakers.


Parts you can turn off
----------------------
Every part of co-op is on. The window's check boxes start ticked: loot and barter through the
host, V.A.T.S. with several players, falls and traps decided by the host. Untick one to turn it
off; every player should tick the same ones.


What is shared
--------------
- The story: quests, stages, objectives and quest variables. Each Pip-Boy lists the same quests.
  A quest reward (caps, experience, items) goes to every player.
- The clock and the calendar.
- The world: doors and locks, what the host's game changes on objects and in containers,
  factions and reputation, and the deaths of the people and creatures the game placed.
- Fights: the same people in the same places fight the same targets. Hits go through the host,
  enemies go for any player, and a player who falls is downed and can be revived by another.
  V.A.T.S. does not stop the game for the other players.
- Loot is taken once: what one player takes is gone for everyone. Barter goes through the host.
- Conversations: their results happen once, and the other players nearby see the lines.
- Companions follow the player who hired them, through doors and fast travel.
- Party saves: when the host saves, each player's place, own quests, inventory, caps, SPECIAL,
  skills, perks, level, experience, condition, worn items, face, hair and name are kept, and come
  back when the host loads. A player who drops can rejoin, and a friend can join a running game.
- Sleeping and waiting: everybody agrees by pressing Rest in their own menu.


Seeing each other
-----------------
- Each player makes their own character at Doc Mitchell's. You see each other once outside.
- The other players walk, run, sneak, jump, swim, sit, fight, reload and get knocked down with the
  game's own animations, wear what they wear, and have their own face, hair and name.
- A purple tick on the compass and a mark on the map show where they are.
- F11 opens the players list: names, who is speaking, mute and volume per player. The host can
  also remove a player there.


Split-screen on one PC (Couchlink)
----------------------------------
Couchlink (https://github.com/cranebeaker/couchlink) starts one copy of the game for each player
on this PC, puts each window on its part of the screen and gives each player their own controller,
or their own keyboard and mouse.
1. Extract this package and run Play.exe once alone, as in Start above. Close the game.
2. In Couchlink's Library, add this package's folder as a game of your own. It shows as
   "Fallout: New Vegas (FNV Co-Op package on nv-rs)".
3. Put the players on their seats and screens, and start it. Player 1 hosts and the others join
   on this PC by themselves: no join code is needed.
4. Everybody presses New Game.
- The game reads each player's controller itself, an Xbox controller or another game controller
  (Couchlink gives each copy NV_PAD=$SEAT, the seat's controller). An Xbox controller gets the
  game's own controller buttons and rumble. Connect the controllers before starting. Keyboard
  and mouse players play as before.
- Each player gets their own copy of the package in Couchlink's folder, with their own saves and
  settings. The saves of this package folder are not used there.
- Friends on other PCs cannot join a Couchlink session: host a normal session for them,
  as in Start above.


If something goes wrong
-----------------------
The game writes a log for each start in userdata\logs (game-....log). Lines with "co-op" say what
the session does. Attach the logs of the host and of a guest to your report. A log may show your
Windows user name in folder paths.

The co-op layer comes from the fnv-coop project (GPL-3.0-or-later):
https://github.com/cranebeaker/fnv-coop
