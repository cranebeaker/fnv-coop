## No game files

The repository and its releases contain no game files: no plugins (`.esm`,
`.esp`), archives (`.bsa`), models (`.nif`, `.kf`), textures (`.dds`), sound
(`.ogg`, `.wav`, `.mp3`, `.lip`), movies (`.bik`), saves (`.fos`), shader
packages (`.sdp`), executables or recordings. Test fixtures are generated by
the tests themselves. The repository hygiene test
(`crates/nvinspect/tests/repo_hygiene.rs`) rejects these file types.

To run nv-rs you need your own legally obtained copy of Fallout: New Vegas.
nv-rs reads that copy's `Data` folder at runtime and never modifies the
installation.

In a Windows package, `app\FalloutNV.exe` is nv-rs's own program under that name
(graphics drivers' game fixes and Windows' per-program sound go by the name), not
the game's; the game's own program is read from the player's installation.

## How the game's behaviour is learned

nv-rs reproduces the original game's behaviour. Its sources are the game's
data files, recordings of the original game, and analysis of the game's
program (`FalloutNV.exe`) with a decompiler. Since 2026-10-05 the maintainer
has also allowed two further sources:

- names and type information from the publicly circulating Xbox 360
  development builds' debug symbols
  ([ADR-0002](docs/adr/0002-xbox-prototype-symbols.md));
- logic translated from the decompiled program, marked in the code
  ([ADR-0003](docs/adr/0003-decompiled-code-in-the-project.md)).

Both are recorded where they are used, so they can be found and removed if
required.

Since 2026-11-02 the project may also use
[fnv_decomp](https://github.com/momusdigital/fnv_decomp), the fnvdecomp
community's C++ reconstruction of the same program
([ADR-0009](docs/adr/0009-fnv-decomp.md)). Its repository grants no licence.
Its authors wrote to the maintainer on 2026-11-02 (spelling
corrected): "You are fine to use everything however you please, you don't have
to credit us, that's why we chose to send it out with no license." The
permission covers their own work, not its `third_party/` folder (zlib, under
its own licence) and not the game or the libraries linked into it. Rust
translated from it, and names, types and layouts taken from it, are marked
where they are used (`fnv_decomp`), like the sources above; no C++ from it is
committed. Material from it is not covered by the project's licence, like
anything translated from the game's program (see Licence below). We thank its
contributors.
